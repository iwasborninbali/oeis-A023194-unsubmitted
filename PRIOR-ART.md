The live [OEIS A023194](https://oeis.org/A023194), read 2026-11-13, attributes the conditional argument to Bernard Schott (2026). It does not claim global uniqueness. The lab's ChatGPT answer identified the conditional character and Claude Code reviewed it. No priority is claimed.
